#  选课系统Controller 层开发文档

## 1. 文档概述

本文档用于说明 **选课系统（Course Management System, CMS）中 Controller 层模块** 的设计目标、模块结构、核心类职责、接口说明以及调用流程。

Controller 层负责：

* 接收业务请求
* 组织业务流程
* 调用实体（Entity）与数据库（Database）接口
* 处理基本的业务与错误反馈

---

## 2. 模块总体结构

### 2.1 模块聚合接口

```cpp
export module cs:controller;

export import :controller.course;
export import :controller.enrollment;
export import :controller.score;
```

`cs:controller` 作为 Controller 层的 **统一导出模块**

---

## 3. Controller 层设计原则

* 每个 Controller 只处理一种业务领域
* 所有数据操作统一交给 Database 层
* Controller 负责流程，Entity 负责行为
* *`Database::singleton()` 单例访问数据库，实现全局数据一致性

---

## 4. CourseController

### 4.1 模块声明

```cpp
export module cs:controller.course;
```

### 4.2 职责说明

`CourseController` 负责 **课程的创建、初始化以及（预留的）教师分配功能**。

主要业务包括：

* 初始化系统内置课程
* 创建新课程
* 课程与教师的绑定（当前版本未启用）

---

### 4.3 类定义

```cpp
export class CourseController {
public:
    void initializeCourse();
    void createCourse(string name, string id, double credit, int capacity,
                      string time = "0", string location = "0");
    bool attributeTeacher(const string &teacherId, const string &courseId);
};
```

---

### 4.4 接口说明

#### 4.4.1 initializeCourse()

**功能**：

* 初始化系统默认课程

**说明**：

* 通常在系统启动阶段调用
* 直接向课程数据库写入预定义课程

---

#### 4.4.2 createCourse()

**功能**：

* 创建并保存一门新课程

**参数说明**：

| 参数名      | 类型     | 说明       |
| -------- | ------ | -------- |
| name     | string | 课程名称     |
| id       | string | 课程编号     |
| credit   | double | 学分       |
| capacity | int    | 最大容量     |
| time     | string | 上课时间（可选） |
| location | string | 上课地点（可选） |

**处理流程**：

1. 构造 `Course` 实体
2. 调用 `CourseDatabase::saveCourse` 持久化

---

#### 4.4.3 attributeTeacher(...)

**功能**：

* 将教师分配给课程（当前版本逻辑被注释）

**返回值**：

* `true`：教师和课程均存在
* `false`：教师或课程不存在

**说明**：

* 教师与课程绑定逻辑预留，便于后续版本扩展

---

## 5. EnrollmentController

### 5.1 模块声明

```cpp
export module cs:controller.enrollment;
```

### 5.2 职责说明

`EnrollmentController` 负责 **学生选课、退课以及课表查询**。

---

### 5.3 类定义

```cpp
export class EnrollmentController {
public:
    bool enrollCourse(const string &studentId, const string &courseId);
    bool dropCourse(const string &studentId, const string &courseId);
    bool getStudentSchedule(const string &studentId,
                            vector<shared_ptr<Course>>& out);
};
```

---

### 5.4 接口说明

#### 5.4.1 enrollCourse(...)

**功能**：

* 学生选课

**校验逻辑**：

1. 学生是否存在
2. 课程是否存在
3. 是否已选过该课程
4. 课程容量是否已满

**处理流程**：

1. 校验学生与课程
2. 校验数据库选课状态
3. 校验课程容量
4. 更新课程实体状态
5. 写入选课记录
6. 更新课程数据

---

#### 5.4.2 dropCourse(...)

**功能**：

* 学生退课

**处理流程**：

1. 校验学生与课程
2. 校验是否存在选课记录
3. 更新课程实体状态
4. 删除数据库选课记录
5. 持久化课程变更

---

#### 5.4.3 getStudentSchedule(...)

**功能**：

* 获取学生课表

**说明**：

* 直接通过 `StudentDatabase` 查询
* 结果通过引用参数 `out` 返回

---

## 6. ScoreController

### 6.1 模块声明

```cpp
export module cs:controller.score;
```

### 6.2 职责说明

`ScoreController` 负责 **学生成绩的录入与查询**。

---

### 6.3 类定义

```cpp
export class ScoreController {
public:
    bool gradeStudent(string studentId, string courseId, double grade);
    std::vector<weak_ptr<Score>>
        getStudentTranscript(const string& studentId) const;
};
```

---

### 6.4 接口说明

#### 6.4.1 gradeStudent(...)

**功能**：

* 为学生录入某门课程成绩

**处理流程**：

1. 校验学生与课程是否存在
2. 构造 `Score` 实体
3. 通过 `ScoreDatabase` 保存成绩

---

#### 6.4.2 getStudentTranscript(...)

**功能**：

* 获取学生成绩单

**返回值**：

* `vector<weak_ptr<Score>>`

**设计说明**：

* 使用 `weak_ptr` 避免 Controller 层持有成绩对象的生命周期
* 生命周期由数据库统一管理

---

## 7. Controller 与 Database 的关系

* Controller **不保存数据**
* Controller **不维护容器**
* 所有数据读写均通过：

```cpp
XXXDatabase::singleton()
```

实现：

* 全局唯一数据库实例
* 数据一致性
* 简化调用关系
