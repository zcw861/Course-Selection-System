# 选课系统Database层开发文档

## 1. 文档概述

本文档用于说明 **选课系统（Course Management System, CMS）中 Database 层模块** 的设计目标、模块结构、核心类职责、接口说明以及数据持久化实现。

Database 层负责：

* 提供全局唯一的数据访问入口
* 封装对PostgreSQL数据库的增删改查操作
* 管理实体对象与数据库表之间的映射
* 保证数据一致性与事务完整性

---

## 2. 模块总体结构

### 2.1 模块聚合接口

```cpp
export module cs:database;

export import :database.student;
export import :database.teacher;
export import :database.secretary;
export import :database.course;
export import :database.score;
```

`cs:database` 作为 Database 层的统一导出模块。

---

## 3. Database 层设计原则

* 每个数据库类对应一种业务实体
* 使用单例模式保证全局唯一数据库连接
* 所有数据库操作使用参数化查询，防止 SQL 注入
* 使用智能指针管理实体对象生命周期
* 封装底层数据库实现，向上提供统一的接口

---

## 4. TeacherDatabase

### 4.1 模块声明

```cpp
export module cs:database.teacher;
```

### 4.2 职责说明

`TeacherDatabase` 负责 **教师信息的持久化存储与查询**，包括：

* 根据教师 ID 查询教师信息
* 保存教师信息（插入或更新）

---

### 4.3 类定义

```cpp
export class TeacherDatabase {
public:
    static TeacherDatabase& singleton();
    bool findTeacherById(const std::string& id, std::shared_ptr<Teacher>& out);
    bool saveTeacher(const Teacher& teacher);
};
```

---

### 4.4 接口说明

#### 4.4.1 singleton()

**功能**：

* 获取`TeacherDatabase`单例实例

**说明**：

* 使用`std::unique_ptr`管理单例生命周期
* 首次调用时初始化数据库连接

---

#### 4.4.2 findTeacherById()

**功能**：

* 根据教师 ID 查询教师信息

**参数说明**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | `const std::string&` | 教师 ID |
| out | `std::shared_ptr<Teacher>&` | 输出参数，存储查询结果 |

**返回值**：

* `true`：查询成功
* `false`：教师不存在或查询失败

---

#### 4.4.3 saveTeacher()

**功能**：

* 保存教师信息（存在则更新，不存在则插入）

**参数说明**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| teacher | `const Teacher&` | 待保存的教师对象 |

**返回值**：

* `true`：保存成功
* `false`：保存失败

---

## 5. StudentDatabase

### 5.1 模块声明

```cpp
export module cs:database.student;
```

### 5.2 职责说明

`StudentDatabase`负责 **学生信息管理及选课相关数据操作**，包括：

* 学生信息的保存与查询
* 选课记录的增删查
* 学生课表查询

---

### 5.3 类定义

```cpp
export class StudentDatabase {
public:
    static StudentDatabase& singleton();
    bool saveStudent(const Student& s);
    bool findStudentById(std::string id, std::shared_ptr<Student>& out);
    bool saveEnrollment(std::string sid, std::string cid);
    bool removeEnrollment(std::string sid, std::string cid);
    bool isEnrolled(std::string sid, std::string cid);
    bool findSchedule(std::string sid, std::vector<std::shared_ptr<Course>>& courses);
};
```

---

### 5.4 接口说明

#### 5.4.1 saveStudent()

**功能**：

* 保存学生信息

**说明**：

* 使用`ON CONFLICT`实现插入或更新

---

#### 5.4.2 findStudentById()

**功能**：

* 根据学生 ID 查询学生信息

**返回值**：

* `true`：查询成功，结果存入 `out`
* `false`：学生不存在或查询失败

---

#### 5.4.3 saveEnrollment()

**功能**：

* 保存选课记录

**参数说明**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| sid | `std::string` | 学生 ID |
| cid | `std::string` | 课程 ID |

---

#### 5.4.4 removeEnrollment()

**功能**：

* 删除选课记录（退课）

---

#### 5.4.5 isEnrolled()

**功能**：

* 检查学生是否已选某门课程

**返回值**：

* `true`：已选
* `false`：未选或查询失败

---

#### 5.4.6 findSchedule()

**功能**：

* 查询学生课表

**处理流程**：

1. 查询学生已选课程 ID 列表
2. 通过 `CourseDatabase` 查询每门课程详情
3. 返回课程对象向量

## 7. ScoreDatabase

### 7.1 模块声明

```cpp
export module cs:database.score;
```

### 7.2 职责说明

`ScoreDatabase` 负责 **学生成绩的存储与查询**，支持：

* 成绩的保存与更新
* 成绩删除
* 按学生 ID 查询所有成绩

---

### 7.3 类定义

```cpp
export class ScoreDatabase {
public:
    static ScoreDatabase& singleton();
    bool saveScore(const Score& s);
    bool deleteScore(std::string scoreId);
    bool findScoresByStudentId(const std::string& studentId,
                               std::vector<std::shared_ptr<Score>>& scores);
};
```

---

### 7.4 接口说明

#### 7.4.1 saveScore()

**功能**：

* 保存或更新成绩

**说明**：

* 使用联合主键 (`course_id`, `student_id`)
* `ON CONFLICT` 实现更新逻辑

---

#### 7.4.2 deleteScore()

**功能**：

* 删除成绩记录

**参数说明**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| scoreId | `std::string` | 格式为 `course_id:student_id` |

---

#### 7.4.3 findScoresByStudentId()

**功能**：

* 查询指定学生的所有成绩

**设计说明**：

* 返回的 `Score` 对象使用 `weak_ptr` 引用 `Course` 和 `Student`，避免循环引用
* 自动检查关联的课程和学生是否存在

---

## 9. 数据库连接与单例设计

* 所有 `Database` 类均使用单例模式
* 使用 `pqxx::connection` 管理 PostgreSQL 连接
* 查询使用 `nontransaction`，写操作使用 `work` 事务
