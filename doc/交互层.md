# 选课系统交互层（UI）开发文档

## 1. 层次定位

交互层位于用户请求与领域层之间，用于实现系统用例并编排业务执行流程。

交互层负责：
- 接收外部请求
- 编排业务流程
- 协调领域实体协作

交互层不负责：
- 业务规则实现
- 实体内部状态维护
- 数据存储细节

---

## 2. 用例驱动设计

交互层以用例为中心进行设计。

典型用例包括：
- 学生选课
- 学生退课
- 教师录入成绩
- 教学秘书排课
- 查询课表与成绩单

每个用例对应一次完整业务操作。

---

## 3. 设计原则

- 以流程为核心
- 不实现复杂业务规则
- 不长期持有领域对象
- 仅调用领域层公开接口

---

## 4. 用例流程示例

### 学生选课

```text
UI / CLI
 → 交互层
 → 获取 Student / Course
 → 调用 Course 实体更新容量
 → 建立选课关系

```
